# Gaurav Soni - Frontend Engineer & Next.js Specialist Portfolio

Official portfolio website of **Gaurav Soni** ([gauravsonidev.com](https://gauravsonidev.com)).

Built with Next.js 15 (App Router), React 19, TypeScript, and Tailwind CSS. Featuring 100/100 Lighthouse benchmark performance, full WCAG 2.2 AA accessibility compliance, and strict production security headers.

## 🚀 Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React
- **Deployment:** Cloudflare Pages / Vercel

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://127.0.0.1:3000](http://127.0.0.1:3000) with your browser.

### Production Build
```bash
npm run build
npm start
```
